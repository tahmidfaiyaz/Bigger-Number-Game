# Bigger Number Game 🎮

A simple Android game developed using Kotlin and XML in Android Studio.

## About
The game displays two random numbers. The player selects the larger number to earn points. Incorrect answers reduce the score.

## Features
- Random number generation
- Interactive number buttons
- Score tracking
- Feedback for correct and incorrect answers

## Technologies Used
- Kotlin
- XML
- Android Studio

## How to Run
1. Clone or download this repository.
2. Open the project in Android Studio.
3. Wait for Gradle sync to finish.
4. Run the app on an Android emulator or device.
